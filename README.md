# agent-toolkit

收录个人使用 agent 时使用的工具合集：skills、插件、环境预设等。

## 目录

```text
agent-toolkit/
├── skills/                 # 可复用的 agent skill
├── opencode/               # OpenCode 预设与插件
├── docs/                   # 使用文档
├── tests/                  # 公共测试入口
└── assets/                 # 静态资源
```

每个组件自包含，后续需要独立发版时可以整体拆出去，不用重写历史。
